# 独立建图修复

源码来自官方 SLAM Toolbox **2.6.10**，下载地址与 SHA-256 由 `sources.json` 锁定。保留上游源码许可，`scan-admission.patch` 是本项目的全部算法改动：移除前端只按 XY 平移选帧的重复筛选，保留暂停、节流和时间间隔；后端 Karto 根据上一帧已接纳扫描，统一判断平移或转角是否足够。静止重复扫描仍由后端拒绝。

仅编译官方前端的七个源文件，复用机器人已安装且版本已核对的 Karto SDK、消息接口及求解器。生成的两个共享库使用 `fairino_` 名称，程序安装在机器人用户目录，不替换系统库，也不改变硬件服务。`mapping.yaml` 是独立的低速建图参数，工作台与独立建图程序使用相同入口。

维护部署入口：

```bash
.venv/bin/python tools/install_mapping_runtime.py --execute
```

安装器先构建内容哈希命名的独立版本，再在仅本机通信的 ROS Domain 197 中验证：短距离前进/返回、原地旋转、静止不重复加帧、暂停/显式继续、合成位姿图保存、地图发布、断流自动暂停及正常退出。全部通过且现场未建图时，才备份并更新 `slam/current` 链接、管理程序和参数。不会重启底盘、清错或使能；下次明确开始新建图时生效。

构建与安装记录在机器人 `~/.local/share/fairino-map-control/slam/<版本>/` 和 `backups/<时间>-mapping-runtime/`。备份含原管理程序、参数及 `previous-runtime.json`；恢复时需一并恢复这三项。没有已验证修复版本时，新建图会报明确部署错误，禁止静默退回原系统程序。
