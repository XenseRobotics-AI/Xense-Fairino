# 网络配置与连接

上半身为 `192.168.58.1`（ROS Domain 0），底盘为 `192.168.58.3`（Domain 1），SSH 用户均为 `fairino`。TP-LINK 桥接设备管理地址为 `192.168.58.11`。

PICO 经 Wi-Fi 向电脑发送输入；电脑运行本项目，通过普通以太网接口连接机器人。控制板到驱动器使用 EtherCAT 总线。

## 配置电脑

```bash
nmcli device status
nmcli connection show
ip -br -4 addr
```

给机器人专用有线连接配置未占用的 `192.168.58.x/24`，Wi-Fi 保留 DHCP 上网。以下连接名和 `.58.200` 为示例，应替换为实际值：

```bash
nmcli connection modify "Wired connection 1" \
  ipv4.method manual ipv4.addresses "192.168.58.200/24" \
  ipv4.gateway "" ipv4.dns "" \
  ipv4.never-default yes ipv4.route-metric 100
nmcli connection up "Wired connection 1"
```

如有权限提示，在修改命令前加 `sudo`。若有线也接入房间网络，可使用 DHCP 加附加 `.58` 地址模式。不同设备不能使用相同 IP；有线和无线同处 `.58` 时，必须核对路由优先级。

## 验证

在仓库根目录执行：

```bash
bash run.sh network
ip route get 192.168.58.1
ip route get 192.168.58.3
ssh fairino@192.168.58.1
ssh fairino@192.168.58.3
```

机器人路由应显示有线网卡及其 `.58.x` 源地址。电脑通过 SSH 使用机器人 ROS 服务，电脑不需要安装 ROS。

## PICO

头显 PC / Server IP 填电脑可达的局域网地址，DHCP 重连后用 `ip -br -4 addr` 核对。运行 `bash run.sh pico service`，头显显示 WORKING，并开启 Controller Tracking 和 Send。普通传输不要求一直插 USB。

TP-LINK Client 模式将机器人内部以太网桥接到无线网络。管理页和机器人 SSH 各用自己的登录信息。

网络能通但不能运动时，检查急停、使能、驱动故障和控制器占用，见 [故障排查](故障排查.md)。代码：[网络检查](../tools/network_check.py)、[机器人状态](../tools/inspect_robot.py)。
