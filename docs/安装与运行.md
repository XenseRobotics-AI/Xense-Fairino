# 安装与运行

所有命令从仓库根目录执行。

## 环境准备

支持 Ubuntu 24.04 x86_64、Python 3.12。首次安装需要联网获取系统与 Python 依赖。

```bash
sudo apt install python3-venv python3-dev python3-gi gir1.2-gtk-3.0 \
  python3-tk openssh-client curl build-essential cmake unzip libusb-1.0-0 fonts-noto-cjk
bash setup.sh all
```

安装入口将环境和资源准备在项目内部：

| 位置 | 内容 |
|---|---|
| `.venv/` | GTK 键控和离线诊断 Python 环境 |
| `.local/pico4/env/` | PICO 独立 Python 环境 |
| `.local/pico4/downloads/` | 按清单校验的 PC Service、APK 与 ADB |
| `.local/pico4/service/` | 接收服务 |
| `.local/pico4/binding-build/` | 使用项目内 SDK 源码构建的 Python 绑定 |

可单独执行 `bash setup.sh base`、`pico`、`diagnostics`。PICO 安装优先使用系统 Python 开发环境；需要时使用已有 Conda 在项目内创建 Python 3.12 环境。所有依赖声明见 [requirements/](../requirements/)，官方资源清单见 [assets.json](../scripts/pico4/assets.json)。

## 首次连接

先按 [网络说明](机器人网络配置与连接说明.md) 配置电脑，再执行：

```bash
bash run.sh network
bash run.sh errors
```

开机有故障时按 [故障排查](故障排查.md) 清除并复查。上半身 SSH 为 `fairino@192.168.58.1`，底盘为 `fairino@192.168.58.3`，密码在终端输入。

## 启动各功能

```bash
bash run.sh base --check
bash run.sh base
bash run.sh joints --group left
bash run.sh joints --group right
bash run.sh joints --group body
bash run.sh body --demo
bash run.sh body
bash run.sh tcp --arm left
bash run.sh lidar
```

上半身各运动入口共用控制锁，同一时间使用一个入口。普通控制会使能；`--check` 只读，`--demo` 离线。身体程序选择预设后需点击执行才运动。

## PICO

首次用 USB 连接头显，开启开发者模式和 USB 调试，执行：

```bash
bash run.sh pico install-apk
```

随后将头显与电脑接入可互通的局域网，在头显填写电脑地址。普通遥操通过 Wi-Fi 传输输入，USB 可拔除。

```bash
bash run.sh pico service
```

保持服务终端运行；另一个终端：

```bash
bash run.sh pico monitor --duration 10
bash run.sh vr
```

头显必须开启 Controller Tracking 和 Send，关闭 A 键切换 Send 的选项。手柄操作、Home 与插值参数见 [遥操说明](PICO遥操有线方案与延迟说明.md)。

## 验证与离线诊断

```bash
bash run.sh test
bash run.sh diagnostics geometry
bash run.sh diagnostics lidar
bash run.sh diagnostics wrist
bash run.sh diagnostics fault-example
```

这些验证与离线分析不使能或驱动机器人。日常日志位于 `.local/pico4/` 或各功能模块 `logs/`；运行生成物由 Git 忽略规则管理。
