# 法奥四舵轮键盘控制

在这台 Ubuntu 笔记本本机运行。通过 SSH 连接底盘 `192.168.58.3`，使用机器人上已有的 ROS 2 Humble。电脑无需安装 ROS。已有依赖为 Python 3、GTK 3、PyGObject、pexpect 和 OpenSSH。

```bash
cd /home/lim/Documents/法奥/fairino_keyboard
bash start.sh
```

在终端输入底盘 `fairino` 用户的 SSH 密码。密码不写入代码或日志。窗口获得焦点后自动进行启动流程。启动会让轮组运动：保持充电线拔下、轮组及车身周围空旷，并能操作物理急停。

| 按键 | 动作（机器人自身坐标系） |
|---|---|
| W / S | 前进 / 后退 |
| A / D | 向左 / 向右横移，保持车身朝向 |
| J / L | 车身向左 / 向右旋转 |
| 组合键 | 可叠加平移与旋转；斜向平移会归一化速度 |
| 松开运动键 | 发送零速度，由底盘控制器减速停止 |
| 空格 / Esc / 停止按钮 | 结束本次控制，发送零速度并请求下使能 |
| 切出窗口 / 关闭窗口 | 停止本次控制并请求下使能，重新操作需重新启动程序 |

默认平移 **0.06 m/s（6 厘米/秒）**、旋转 **0.10 rad/s（约 5.7°/秒）**，均为旧默认值的两倍。窗口中的滑条和数字框分别调节平移、旋转；平移范围 0.01–0.20 m/s，旋转范围 0.01–0.40 rad/s。这里是本程序的调试范围，不代表机器人的额定性能上限。`--linear`、`--angular` 可指定启动时的数值；每次启动恢复指定值，不记忆上次调速。

先松开全部运动键再调速，按住运动键时调节项会变灰。修改数值后程序会等待机器人端确认，之后再次按运动键使用新速度；在等待期间按下的键必须松开重按。数字框输入后按回车，或点击“继续键盘控制”按钮恢复键控。速度指令由底盘控制器平滑加减速，短距离或转向未就绪时，实际速度可能低于选定值。左右方向均以机器人本身为准；站在机器人前面观察时，与观察者左右相反。

## 启动回中立位

1. 要求八个电机均未使能、底盘静止、上下身故障均为 0，且实时反馈正常。不会自动清除故障。
2. 暂停原有底盘运动控制器，建立独立的临时控制器。
3. 仅使能转向轴 `J1/J3/J5/J7`（掩码 85），行走轴 `J2/J4/J6/J8` 保持未使能。
4. 通过转向轨迹控制器，将四个转向轴缓慢移动到现有标定坐标的 `0 rad`。五次插值的理论峰值不超过 0.20 rad/s，实测到位容差 0.02 rad（约 1.15°）。这里不调用 `zeroing()`，不改变编码器零点。左右轮组安装方向相反，0° 表示滚动方向沿车身前后轴。
5. 回正通过后先下使能，再切换到独立的底盘控制器，核对零速度和控制接口后使能全部电机，显示“就绪”。

回正期间不接受方向键。回正超时、跟踪误差、急停、反馈异常或通信异常均中止启动。回正逻辑依据当前机器人配置；若以后更改关节标定或轮组安装，应重新核对 0° 的实际方向。

SSH 连接后，首次 ROS 发现最多等待 15 秒；窗口会分别提示等待底盘状态或上半身急停状态。必须同时收到两路新鲜反馈才能继续，运行中的 0.4 秒反馈保护不变。

## 控制链路和退出

GTK 按下/松开事件 → SSH JSON 心跳 → 底盘侧保护程序 → `/fairino_keyboard/cmd_vel` → `fairino_keyboard_chassis` → 原有硬件插件 → EtherCAT。

临时底盘控制器使用原有运动学配置，并降低速度/加速度限制。原网页的 `/cmd_vel` 不进入这个临时控制器。正常退出时下使能并卸载临时控制器；原来的底盘运动控制器保持未激活，避免自动恢复网页控制。键控运行本身不修改厂家启动配置、持久参数或上半身控制程序。

调速版临时控制器：平移/旋转上限为 0.20 m/s、0.40 rad/s，加速度上限为 0.20 m/s²、0.40 rad/s²；行走轮指令上限 6 rad/s，反馈超速保护为 7 rad/s。启动时根据实际四轮半径和安装位置核对平移与旋转叠加后的轮速，配置不满足范围时拒绝继续。轮组转向限制和启动回正速度保持原值。

保护程序检查底盘和上身急停反馈的新鲜度（0.4 秒）、SSH 往返心跳（0.45 秒）、单轴故障、使能状态及异常轮速。停止不等于硬件安全急停；如果厂家拒绝下使能或连接丢失，窗口/日志会明确显示未确认，需现场检查并使用物理急停。之前 J6 的过载原因尚未排除，首次实测应分开短按前后、横移、旋转。

```bash
# 真实机器人只读检查：无使能、无回正、无速度指令
bash start.sh --check

# 不使能电机的接口自检：临时加载控制器并验证私有话题，完成后卸载
bash start.sh --prepare-check

# 离线窗口：不连接机器人，检查按键与松键、失焦行为
bash start.sh --demo

# 指定初始速度，也可以在窗口中修改
bash start.sh --linear 0.10 --angular 0.20

# 核心保护与按键测试
python3 -m unittest -v
```

运行记录保存在本目录 `logs/`，包括动作结果、故障码、角度及使能反馈；不记录密码。
