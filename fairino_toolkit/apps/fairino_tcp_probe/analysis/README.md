# TCP 坐标与旋转漂移核对（2026-10-06，修正前快照）

后续状态：法兰偏移现已集成到运行程序，见上级 README。本文和原 JSON/图片记录修正前的诊断；`model_audit.py` 的连续模拟调用当前程序，更新后再次运行的连续模拟结果会不同。新版连续轨迹验证结果保存在 `flange_runtime_validated.json`。

结论：没有在这次测试中发现厂家纯 FK/IK 库与所配单臂 URDF 不一致的明显错误。现用程序把 DH 最后一个坐标系原点当成实际 TCP，遗漏了腕心到法兰安装面约 106 mm 的固定偏移；又未加入单臂基座到胸部/地面坐标系的旋转。因此原点数值近乎不变时，真实工具安装面仍会画弧，XYZ 也不保证与地面水平或竖直。此前界面中“厂家末端坐标系、工具偏置为零”的说法不足以描述它实际上控制的是腕心，这是程序的坐标定义问题。

这次只读取本地文件、已有实机关节日志和公开厂家尺寸图，并执行离线测试；没有发送使能或运动命令，也没有修改当前运行控制程序。`flange_check.py` 是独立的修正验证脚本，不是新的实机启动入口。

## 证据与测试

1. 独立解析左、右 URDF 的每个 `origin xyz/rpy`、`axis`，通过 Rodrigues 旋转逐关节计算；没有复用程序的 DH 参数来充当另一套模型。左右臂各 200 个随机姿态。两份 URDF 的基座 XY 微小偏置分别为 `[-0.88174,+0.33281]`、`[+0.88174,-0.33281]` mm；原始位置差约 0.945 mm。减去这项坐标原点差后，最大位置差分别为 0.003958、0.004177 mm，最大姿态差分别 0.005338°、0.000812°。误差量级与 URDF 的圆周率截断和左臂 J7 轴小偏量相符；不是实机标定精度。

2. `wrist2_Link.STL` 的工具安装面是末端坐标中的 `x ≈ -106 mm` 平面，中心约为 `[-106,0,0]` mm；DH/URDF 末端原点在腕关节轴交汇处。STL 该平面的环形半径范围约 15.99–31.2 mm，与厂家法兰图的内径 31.5 mm、外径 63 mm 对应；另有 x=-100 mm 平面，两者间距 6 mm，也与厂家法兰台阶尺寸相符。这是本模型的几何测量，夹爪尖端还需额外工具偏置。

3. 回放 `20261006-165908.jsonl`、`20261006-170414.jsonl`、`20261006-170553.jsonl`，共识别 45 段长按，其中 24 段旋转。旋转中按实际关节反馈重建的腕心最大位移 0.09199 mm；按关节指令重建的腕心位移接近浮点数误差。最近一次长 Rz 负向旋转约 41.63°、持续约 21.06 s，腕心最大位移 0.0366 mm，但模型法兰中心移动 70.12 mm。70.12 mm 是模型与编码器反馈重建值，并非外部测量仪测得的实机值。

4. 当前连续算法模拟：从日志中的两种姿态出发，对两臂各三个旋转轴的正负方向做 20 s、50 Hz 轨迹更新、10 Hz 逆解更新测试。腕心位置最大数值漂移约 3.3e-12 mm；所以此次肉眼可见的大幅旋转位移，不能归因于腕心积分漂移。当前模型的后三级关节共点，纯腕部转动不会改变这个原点位置。普通平移仍可能有连续近似引入的小旁向漂移，例如日志中一段 X 前进约 227.13 mm 时，Y 变化约 -0.85 mm，这与旋转中数厘米的偏移不是同一量级。

5. 修正法兰中心的离线试验：先固定法兰中心位置并改变姿态，再用 `p_wrist = p_flange - R * [-106,0,0]` 得到厂家 IK 所需的腕心目标。24 组方向/姿态测试中 21 组完成 20°，其余三组在 16.2°/17.6°/17.6°处遇到模型 J4 限位并停止，没有绕过限制。累计 4714 个有效目标，厂家 FK 检验的法兰位置误差最大约 4.3e-13 mm，独立 URDF 重建的最大法兰漂移约 0.00310 mm。这证明“补入法兰偏移”的数学修正可行，不代表连续控制实机已验证。

## XYZ 与地面

单臂文件的根为 `base_link`，未提供安装到胸部后的朝向，更未提供胸部相对重力方向。当前方向是在单臂基座中定义，所以这些轴依然互相正交，但整体不一定朝向地面平行/垂直方向。日志的一段 X 负向运动重建为 `[-64.044,-0.218,-0.042]` mm，说明它主要沿模型 X 走，而不是能证明模型 X 在实机上水平。

统一到胸部需要两臂到胸部的固定安装变换；若进一步要求始终与地面水平/竖直对齐，即使腰部倾斜也保持这个方向，还需胸部相对地面的姿态。胸部随腰部旋转/倾斜时，胸部轴本身会随之转动。当前模型与日志没有足够证据填写这一安装变换，不能仅凭轴名称互换或猜一个 90°旋转。
