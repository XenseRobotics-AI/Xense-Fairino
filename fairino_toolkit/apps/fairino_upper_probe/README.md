# 上半身关节调节与绝对角度运动

新增的身体高度/姿态程序使用 `bash start_body.sh`，与本页原单关节入口独立。
支持高、中、低参考姿态，默认每轴最高 5°/s、前倾 0～45°、腰旋转 ±90°，侧倾 ±15°仅在高位区域且前倾≤5°时开放。
首次使用需要明确胸部竖直基准；离线预览用 `bash start_body.sh --demo`。
完整运行与标定说明见 [身体高度控制说明](body_control/README.md)。

在笔记本运行，通过 SSH 连接上半身 `192.168.58.1`，ROS Domain 0。正常启动会使能上半身全部 **J1–J20，包含双臂**，并保持当前位置；一次只移动一个关节，支持 0.5° 点动和输入绝对目标角度，其余 19 轴保持各自目标。底盘程序不受修改。

```bash
cd /home/lim/Documents/法奥/fairino_upper_probe
bash start.sh
# 直接显示左臂分页（仍使能全部 20 轴）
bash start.sh --group left
```

窗口分为左臂 J1–J7、右臂 J8–J14、头部/躯干 J15–J20 三页；`--group right` 或 `--group body` 指定启动页，不带参数默认头部/躯干。左右命名依据厂家 `art7.urdf` 和 SDK 配置，实际运动方向仍需现场辨认。点击标签只切换选择，不发送运动指令，也不重复使能。运动期间分页和关节选择锁定。所有页面的关节反馈都会更新，辨认记录统一保存至 `joint_mapping.json`。

输入 `fairino` 的 SSH 密码后保持窗口焦点。启动要求全部 20 轴未使能、静止、无故障，急停已释放，其他上半身运动控制器未活动。程序先加载二十轴位置控制器，核对各轴目标与实测角度，再发 `switchmode(position,1048575)` 和 `enable(1048575)`。掩码 1048575 的低 20 位全部为 1。

临时控制器明确设置 `set_last_command_interface_value_as_state_on_activation: false` 和 `open_loop_control: false`，每次激活从当前实测位置初始化保持目标，避免沿用上一次下使能前的旧目标。使能前仍要求各轴指令与实测差值不超过 0.001 rad（约 0.0573°）；检查失败时显示目标、实测值和差值，不会继续使能。

2026-10-12 更新：按用户要求，本关节调节程序全程关闭**实测速度超标退出**，包括运动轴和保持轴；使能完成后也不会恢复该检查。使能阶段最长 12 秒，GPIO 急停、硬件故障、反馈新鲜度、通信心跳和位置保持检查继续工作。该配置通过独立 `JointProbe` 入口生效，TCP 键控和 VR 的共享基类设置保持原样。

正常使能会接通保持力矩并切换抱闸状态，即使没有点动轨迹也可能产生位置调整。本次可调速度改动仅做离线验证，未执行实机运动。

| 按键 | 操作 |
|---|---|
| 1–7 | 选择当前页第 1–7 个关节；头部/躯干页只有 1–6 |
| 右箭头 → / 左箭头 ← | 选中轴角度增加 / 减小 0.5° |
| 空格 | 中止当前点动或目标角度运动，全部关节继续使能并保持位置；运动时即使焦点在输入框中也有效；使能阶段按下则取消启动 |
| Esc / 关闭窗口 | 结束程序，取消轨迹并请求全部 J1–J20 下使能 |
| 窗口失焦 / 断线 / 故障 | 结束本次控制，请求全部 J1–J20 下使能 |

窗口顶部可调“点动最高速度”，至少 0.1°/s，默认 0.5°/s，步进 0.1°/s；原 1.0°/s 软件上限已取消。每次位移仍为 0.5°，程序通过调整平滑轨迹时间来调速：默认每步约 1.98 秒，0.1°/s 时约 9.48 秒，1.0°/s 时约 1.04 秒。点动时长仍按 `1.875 × 0.5 / 设定速度` 计算，另有 0.1 秒起始段；仅拒绝无法用 ROS 纳秒时间戳表示的极短时长。显示时间不含通信等待。调好后点击“恢复方向键控制”再点按方向键。输入框内的方向键和数字仅用于编辑速度；正在点动时控件锁定，参数固定在本次请求中。每次启动恢复默认 0.5°/s。

长按不连发；松开方向键不会取消已经开始的一步。忙碌时的按键不排队。每步完成后所有关节继续使能，其他 19 个关节保持原目标，不再重复使能和下使能。空格是取消点动并保持，Esc 才是结束并下使能。

## 输入绝对目标角度

2026-10-12 新增。先退出遥操或其他上半身控制程序，再运行：

```bash
bash /home/lim/Documents/法奥/fairino_upper_probe/start.sh --group body
```

1. 选择关节，确认窗口中的 J 编号与实物部位对应。
2. 在“目标角度（°）”中填写控制器反馈坐标下的绝对角度，例如 `-70`。可先点击“填入当前角度”，再修改数值；切换关节会清空目标输入。
3. 目标运动的“最高速度”至少 0.1°/s，默认 3.0°/s；原 3°/s 软件上限已取消，可直接填写更高的有限数值。窗口显示当前角度、目标差值和预计运动时间。
4. 点击“执行到目标”才会发送请求。编辑、填入当前角度或切换关节本身均不发送运动；执行过程中目标、速度和选轴锁定，不排队追加动作。
5. 按空格或点击“中止运动”可取消剩余轨迹并保持。完成后可以在原观察栏记录部位、方向和手动测试结果，点击“保存辨认记录”。

机器人端根据执行前最新实测角度重新计算轨迹，但保持输入的绝对目标不变。使用起终点速度、加速度均为零的五次轨迹，时长 `T = max(0.1, 1.875 × |目标角度 − 当前角度| / 最高速度)` 秒，另有 0.1 秒起始段；例如移动 10°、最高 3°/s，预计约 6.35 秒。程序根据用户填写的速度规划峰值，不再另设固定速度上限；这不是驱动器硬限速或设备能力声明。请求中的自定义时长不生效，零、负数和非有限速度仍会被拒绝。

角度以当前反馈零位为准，不是相对启动角度；该功能不自动寻找机械限位，也没有装入未经确认的腰腿 URDF 范围。应手动逐步接近待测位置，避免用大幅目标撞限位。测试记录属于人工观察，不会自动变成控制器限位。日志中的 `step.kind=target` 包含目标、起点、速度和轨迹时长，另有原始反馈与故障快照。

全部关节均无相对启动位置 ±3° 的目标限制。“相对启动”列仅显示累计角度。程序没有加载厂家物理行程、碰撞约束或折叠机构逆运动学；需按实际机构行程操作。运动过程的路径跟踪误差检查已取消：所有轴的 ROS `path_tolerance` 中位置、速度和加速度均设为 `-1`，明确清除容差而非回退默认值，语义见 [ROS Humble 控制器文档](https://control.ros.org/humble/doc/ros2_controllers/joint_trajectory_controller/doc/userdoc.html#actions)。终点到位检查仍保留，未运动的 19 轴偏离各自保持目标超过 0.3° 仍会结束控制；每步完成后更新选中轴保持目标，空闲时监测全部 20 轴。

原运动轴 2°/s 或设定速度阈值、保持轴 0.5°/s 的超速退出逻辑在本程序中均已关闭，状态栏和日志会显示这一点。启动及接受下一条轨迹前的静止条件仍保留。反馈超时为 0.4 秒，SSH 往返心跳超时为 0.45 秒，任一关节意外退出使能会结束整次控制。厂家驱动的硬件保护参数未修改。

程序不清错、不校零、不修改厂家持久参数。关闭时先请求全部下使能，再核对实时反馈，确认后卸载临时控制器。如果使能请求在故障发生后才返回，程序会再次请求下使能；无法确认请求结束或电机停止时，会明确报告未确认。

用户已实测辨认：J15 为头部，具体转动方向待确认；J16 为腰部旋转；J17 为整体左右倾斜；J18–J20 构成两连杆、三关节的折叠结构，影响高度和前后姿态。具体正负方向记录保存在 `joint_mapping.json`；此文件不会由升级覆盖。
