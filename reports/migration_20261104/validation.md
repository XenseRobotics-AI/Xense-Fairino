# 验证记录

本次迁移仅运行电脑端离线验证，没有连接机器人、安装远端服务、使能电机或发送运动目标。

## 本次验证范围

- Python 语法、YAML、行为树 XML、底盘 URDF 解析。
- Nav2 配置与模型/共享速度参数生成结果一致。
- 174 项回归：建图与定位、导航生命周期与速度门控、底盘回正/反馈/退出、故障复位流程、原始里程计、建图键控会话和分发独立性。
- 所有公开命令 `--help` 在网络/机器人命令拦截器下通过。
- 控制栈、地图/定位、导航安装 payload 生成和语法检查，不执行远端安装。
- 机器人平铺源码不依赖电脑端 fairino_slam 包；manager/reader 支持没有 __file__ 的 exec 加载。
- 独立目标目录运行及包资源检查；原仓库已有文件通过迁移前后哈希核对。

最终机器可读结果见 [validation.json](validation.json)。依赖安装仅用于电脑端项目虚拟环境。
