# TacCap 夹爪、转接件与固定工具点

网格来自用户提供的 `/home/lim/models/转接.STEP` 和
`/home/lim/models/从夹爪-外发版本.STEP`，来源 SHA256 与网格校验在
[manifest.json](manifest.json)。原始 STEP 单位为毫米；桌面显示时转换为米。
CAD 转网格仅在电脑离线进行，机器人端不需要 CAD、OpenGL 或网格文件。

## 使用

工作台右侧默认显示两侧夹爪和转接件，可关闭「显示夹爪 / 转接件」。
它们随实测手臂姿态运动，手指按夹爪会话的实测开度开合。
在工作台「夹爪调试」点击只读扫描连接，或启动已勾选夹爪的 PICO 会话，即可提供反馈，
不额外打开串口。反馈超过 0.5 秒时保留最后开度并标灰；未连接时以张开姿态作灰色参考。
内部连杆只做近似开合，不用于接触或碰撞测量。绿色点表示固定参考 TCP，不随开合移动。

在「PICO 遥操」：

1. 打开「安装角度 / TCP 设置与预览」，选择实际安装的手臂、调整各自安装角度，
   核对固定工具点。未安装的一侧继续使用法兰中心。
2. 核对实装后勾选对应侧「已核对实装角度及 TCP」并保存。修改安装角度、
   是否安装或固定工具点会撤销相应核对标记。
3. 「遥操 TCP」选择「带夹爪 · 固定指尖中心」。这会勾选 Trigger 夹爪遥操；
   如只需要改变手臂控制点，可单独取消夹爪开合控制。
4. 夹爪速度默认 0.75 rad/s，可设 0.01–1.0 rad/s，启动时生效。
   原手动调试页仍默认 0.25 rad/s。力矩仍为 1.1 Nm。
5. 左右最大开度可分别设为 0–100%；Trigger 全松到全按线性对应所设上限到闭合。
   例如 60% 上限、50% 扳机对应 30% 实际标定行程目标，设备标定不会被改写。

初次按用户说明设置向内旋转 90° 时，左侧安装角度为 +90°、右侧为 −90°。
当前保存的工具配置为左侧 **+180°**、右侧 **−180°**，两侧均安装且 `confirmed=true`；
这是工作台后续保存的配置，提交保留这些值。角度始终相对 CAD 的零位定义，
不是在上一次设置上叠加的增量。
固定 TCP 默认取 CAD 张开姿态的指尖中心，实机前需在工具设置中核对具体抓取点。
是否完成核对以界面保存的 `confirmed` 标记为准。法兰 TCP 模式继续可用。配置保存在
[tool_config.json](tool_config.json)，显示和控制共用；切换工具需先结束遥操。

独立入口使用同一配置：

```bash
bash run.sh vr --tcp-tool taccap --grippers --gripper-speed-rad-s 0.75
```

`--tool-config PATH` 可指定另一份配置。`--check --tcp-tool taccap` 允许检查未确认
的几何，但 `--execute` 会在建立机器人连接前拒绝未确认的安装配置。
此功能没有实机碰撞检测；本次实现与验证没有执行机器人运动。

## CAD 依据与坐标

从 STEP 的圆柱、平面提取到：

- 转接件外径 63 mm，总厚 13 mm，CAD 轴为 +Y。
- 转接件凹槽 Ø34.4 mm、深 8 mm，占 Y=5～13 mm。
- 夹爪定位凸台 Ø34 mm，中心在 X=0、Y=-15.75 mm；
  安装面 Z=38.5 mm，凸台到 Z=46.5 mm。
- 因此在转接件坐标中，夹爪变换为 `T(0,51.5,15.75) Rx(90°)`。
- 原机器人手腕外法兰中心在手腕局部 `(-106,0,0) mm`。
  工具外伸方向是手腕 -X。安装角度 0° 令夹爪 CAD +X 对齐手腕 +Y；
  正角度绕向外轴旋转。两侧角度分别配置，不能由这两个独立 CAD 文件推断实装角度。

提供的 STEP 是张开姿态。初始固定参考点取其指尖中心
`(0,20.825,-152.712) mm`，在安装角度 0° 时对应：

- 法兰到 TCP：`(-204.212,0,36.575) mm`；
- 手腕原点到 TCP：`(-310.212,0,36.575) mm`。

以 +90° / −90° 安装为例，法兰到参考 TCP 的偏置为：
左 `(-204.212,+36.575,0) mm`，右 `(-204.212,-36.575,0) mm`。
当前 +180° / −180° 配置下，两侧偏置均约为 `(-204.212,0,-36.575) mm`。
显示网格和 TCP 同时使用各自的安装角度，不能只旋转外观而保留原工具点。

这包含侧向偏置，不能只加一个轴向长度。该点是 CAD 初始参考点，
不是已标定的闭合抓取点；需要按实际抓取用途核对/修改。
夹爪开合不改变固定 TCP。TCP 姿态轴沿用原法兰约定，只改变旋转中心。

共享数学在 [tool_frames.py](../../apps/fairino_tcp_probe/tool_frames.py)：
客户端正解添加工具变换、逆解移除工具变换；机器人接收端用相同配置独立正解验证，
并检查配置指纹。Home、身体升降请求也携带工具标识，避免混用不同 TCP。

## 速度与延迟

原 PICO 固定为 0.25 rad/s。以此前右夹爪 1.239 rad 标定行程计算，理想匀速
全行程约 4.96 秒；0.75 rad/s 约 1.65 秒。实际时间受起停、负载和 SDK 限力矩影响，
本次没有测量提高速度后的实机全行程。

共享夹爪客户端目标发送周期从 40 ms 改为 10 ms，接收循环从 20 ms 改为
10 ms，周期反馈从 100 ms 改为 50 ms。目标采用覆盖更新，不积压过时开度。
这是最多 100 Hz 的调度设置，不代表无线实测频率。SDK 的 100 Hz 状态流、
内部插值、0.25 秒目标超时保持及现有故障/温度/包络检查继续生效。

夹爪模型和 PICO 显示消息按 10 Hz 调度，使用实测开度及原始采样年龄；
刷新显示不会把旧反馈变成新反馈。2026-10-20 只读复查时左右夹爪均在线且未使能，
行程分别约 1.222917 / 1.238645 rad，实测开度约 99.5% / 100%。
上限 60% 时对应相对闭合的电机转角约 42.0° / 42.6°，不是两指夹角。
本次未执行开闭运动；离线开合截图及只读采集在 `logs/20261020-gripper-sync/`。

## 开合显示模型

源 STEP 有 45 个 solid：0–26 为固定主体，27–35 与 36–44 分别为两组夹指。
分别生成 `gripper_body.stl`、`jaw_positive.stl`、`jaw_negative.stl`，
以 CAD 中观察到的齿轮轴心 `(±19.95,0,-10) mm` 为绕 Y 轴的显示转轴。
归一化开度 1 使用原始张开姿态，0 使用尖端间隙约 1 mm 的近似闭合姿态，
中间按实测归一化开度插值，角度约为两侧 ±29.057°。
这不是电机转角或完整连杆运动学，也不参与 IK、目标限制、接触估计或固定 TCP 计算。

## 再生成

构建工具依赖 `cadquery-ocp==7.8.1.1.post1`、`vtk==9.3.1` 和 numpy，
只用于离线生成，不加入运行依赖：

```bash
python tools/prepare_gripper_model.py \
  --source /home/lim/models --output /tmp/fairino-gripper-cad \
  --display-output models/taccap
```

活动夹爪网格合计约 8.47 万三角形；简化保留拓扑/边界，绝对误差参数 0.08 mm。
控制几何依据 CAD 配合面和工具配置，不从简化网格推算。
